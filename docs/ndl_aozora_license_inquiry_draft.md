国立国会図書館 NDLラボ ご担当者様

突然のご連絡失礼いたします。早稲田大学 知覚情報システム研究室（PCL）の阿部雄斗と申します。
LLM-jp プロジェクトの一環として、日本語の対話音声生成モデルの研究開発を行っております。

貴館 GitHub（ndl-lab/hurigana-speech-corpus-aozora）にて公開されている
「青空文庫振り仮名注釈付き音声コーパス ver.2」について、音声データの利用条件を確認したく
ご連絡いたしました。当方では、本コーパスに含まれる音声ファイル（サピエの DAISY データに
由来する朗読音声、約4,892時間）を、**音声生成モデルの学習データ**として利用することを
検討しております。

つきましては、以下の点についてご教示いただけますでしょうか。

1. 本コーパス同梱の音声ファイル（朗読音声）について、**著作隣接権（実演家・レコード製作者の
   権利等）**の扱いはどのようになっておりますでしょうか。青空文庫の原テキストは著作権保護期間
   満了と理解しておりますが、朗読の実演・録音についての権利関係をご確認させてください。

2. 本コーパス（特に音声データ）が配布される際の**ライセンス／利用許諾条件**をご教示ください。
   GitHub リポジトリに LICENSE ファイルがございますが、音声データに適用される条件を明確に
   把握したく存じます。

3. 想定している利用形態は、**音声をそのまま再配布するのではなく、機械学習モデルの学習に用い、
   学習済みモデル（音声そのものを含まない）を配布する**というものです。さらに、将来的に当該
   モデルを**商用利用・商用配布**する可能性がございます。このような利用が許諾の範囲に含まれるか、
   制約がある場合はその内容をご教示いただけますと幸いです。

お忙しいところ恐れ入りますが、ご回答のほどよろしくお願い申し上げます。
