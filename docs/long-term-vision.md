# 長期ビジョン: 人間っぽい対話AI

## 目指す姿

単なる音声対話モデルではなく、**人間らしい対話能力**を持つAIを目指す。

## 知識の限界の自覚（Epistemic Humility）

最も重要な要素の一つとして、**わからないことを正直に「わからない」と言える能力**がある。

### 現在のLLMの問題

- もっともらしく答えてしまう（ハルシネーション）
- Chain of Thought を使っても、知らないことについて自信ありげに誤った回答を生成する
- 「知識の限界」を自覚する仕組みがない

### 人間の自然な対話での振る舞い

人間は知識の限界に達したとき、様々な形で表現する：
- 「うーん、それはちょっとわからないな」
- 「聞いたことはあるけど、詳しくは知らないかも」
- 考えた末に「やっぱりわからない」
- 「自信ないけど、たぶん...」（不確実性の表明）

これらは対話において**信頼性**と**人間らしさ**の両方に寄与する。

### 音声対話モデルならではの可能性

テキストベースのLLMと異なり、音声対話モデルでは：
- 「えーっと...」「うーん」といった**躊躇・逡巡の表現**が自然に使える
- 声のトーンや間（ま）で**確信度**を表現できる
- 考えている途中の沈黙が許容される

## 実現へのアプローチ（検討段階）

### 短期的に取り組めること

1. **学習データに「わからない」応答を含める**
   - 対話データの中で、知識の限界を示す応答例を意図的に用意する
   - 「わからない」「知らない」「ちょっと自信ないけど」等の表現を含む自然な対話
   - 合成対話データで「知らない質問に対して正直に答える」パターンを生成

2. **音声的な躊躇表現の学習**
   - フィラー（「えーっと」「うーん」）を含む対話データを活用
   - 考えている間の沈黙や言い淀みを自然に生成できるようにする

### 中長期的に必要なこと

3. **Calibration の改善**
   - モデルの自信度（出力確率）と実際の正確性を一致させる
   - 自信がないときにそれを対話に反映する仕組み

4. **知識境界の明示的モデリング**
   - モデルが「知っていること」と「知らないこと」を区別する能力
   - 内部状態から不確実性を推定し、応答生成に反映する

5. **評価指標の開発**
   - 「わからない」と言うべき場面で適切に言えているかの評価
   - ハルシネーション率と「わからない」応答の適切さのバランス
