# レポート② ASR-CER 客観評価レポート

## 手法

faster-whisper large-v3 で生成 wav を書き起こし、モデル自身のテキストトラック
(generated_tokens の row 0) との CER を測定する**自己整合性スコア**。
低いほど「生成音声がモデルの意図したテキストと一致 = 破綻していない」。
5 サンプル × 3 条件。

## 結果

| 条件 | CER | 系譜 | 商用 |
|---|---|---|---|
| **v0c** (現行運用版) | **36.1%** | LaboroTV 含む | ❌ NC |
| from18000_moshiko (旧試作) | 57.2% | moshiko base、ccaudio なし | ✅ |
| **v0d** (新リビルド) | **63.6%** | moshika + ccaudio | ✅ |

## 所見

- **v0d は v0c より大幅に悪化**、しかも ccaudio なしの旧試作 from18000 よりも悪い。
- コスト分解:
  - LaboroTV を抜くだけで 36% → 57% (約 21pt 悪化)
  - さらに ccaudio を足すと 57% → 64% (さらに 6pt 悪化)
- → **ccaudio は品質を補填するどころか、さらに下げている**。
- 書き起こしにも音声破綻が明確: 「うまーーーーーーー」(母音暴走)、
  「ドキュアクバータック」(語崩壊)。ASR の誤りでなく生成音声そのものの劣化。

※ n=5 と少サンプルだが、書き起こしの崩れ方は定性的にも明確。

## アセット

- CER JSON: `~/projects/icml-mlforaudio-2026/results/asr_cer_v0d_eval_compare.json`
- 聴き比べ wav: `output/v0d_eval_compare/{v0c,v0d,from18000_moshiko}/generated_wavs/`

# レポート③ 学習データ品質 A/B + バグ発見レポート

## 手法

ccaudio が CER を悪化させた原因を切り分けるため、3 コーパス (LaboroTV /
J-CHAT-mono / ccaudio) の q16 parquet を**同一 Mimi codec でデコード**し、
モデルが実際に食べている音声・テキストを比較した。各 5 サンプル。

## デコードした書き起こし

**LaboroTV** — 全 5 本クリーンな日本語:
- 「わたしいつも公園なんかで一人で歌っているんです」
- 「三城紗江子さんが事故に遭ったのって大使館のすぐ裏だよな」

**J-CHAT** — 全 5 本まともな対話日本語:
- 「これを聞いてほしい方は松山さんを探して下さい…」

**ccaudio** — **5 本中 4 本が破損**:

| # | テキスト | 判定 |
|---|---|---|
| 00 | 情熱ものづくりハイスクール こんにちは… | ✅ OK |
| 01 | `e crois pas que c'est assez difficile le truc...` | ❌ 純フランス語 |
| 02 | `a a a a a a a a a a a a a a` アニメの声優… | ❌ Whisper hallucination |
| 03 | `professionnel` エド東京人セミナー… | ❌ 仏語混入 |
| 04 | `18azyen イダ・トーキョージンセミナー` | ❌ ローマ字崩れ |

## 根本原因: フィルタのバグ

`tools/ccaudio_to_parquet.py` の `non_japanese_ratio()`:

```python
for ch in text:
    if ch.isspace() or ch.isascii():   # ← バグ
        continue
    n += 1
    if not _is_ja_char(ch):
        bad += 1
return bad / n if n else 0.0
```

`ch.isascii()` が **ASCII 文字を全てスキップ**する。フランス語・英語は全文字が
ASCII なので、純フランス語テキストは「非日本語率 = 0.0」と判定され、
`non_ja > 0.10` フィルタを**完全に素通り**する。

意図は「日本語 podcast に英単語が少し混じっても罰しない」だったが、実装が極端で
**100% 仏語/英語の hallucination が検出不能**になっていた。
slice 0 calibration「300 中 70 通過」の 70 本に、この破損 cut が大量混入していた。

## 修正方針

ASCII **letters** は非日本語としてカウントする (digit・記号は中立のまま)。
これで「日本語 + 少しの英単語」は低スコア、「純仏語/英語」は ~1.0 となり正しく弾ける。

## アセット (聴き比べ用 wav)

  jchat/      jchat_00..04.wav
  ccaudio/    ccaudio_00..04.wav
