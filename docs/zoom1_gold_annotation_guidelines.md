# 対話音声 書き起こし修正タスク 作業ガイド

2人の会話音声を聞いて、**自動で付いている書き起こし（文字）の間違いを直す**お仕事です。
ゼロから入力する必要はありません。すでに入っている文を、聞こえた通りに直してください。

## 画面の見方

- 上下に**2本の波形**があります。**上＝話者A**、**下＝話者B**（別々の人の声）。
- それぞれの波形に区切り（セグメント）があり、各区切りに文字が入っています。
- 再生しながら、各区切りの文字が**実際に聞こえる言葉と合っているか**を確認します。

## 直すときのルール

### やること
- **聞こえた通りに直す**。聞き間違い・抜け・余分な文字を修正する。
- **フィラー・言いよどみ**（あー / えー / えーと / うーん / あの / まあ など）は、聞こえたら**ひらがなで書く**。
- **相づち**（うん / はい / へー / なるほど など）も、**その人の波形（A か B）**に書く。
- **声が重なっている所**は、**A・B それぞれの波形に両方とも書く**。小さい方を省略しない。
- **笑い声**は `(笑)` と書く。
- **聞き取れない所**は無理に当てず `(不明)` と書く。
- **数字**は算用数字で書く（例：100、3つ）。

### 使ってよい記号は2つだけ
`(笑)` と `(不明)` のみ。それ以外の `( )` 付きメモ（例：`(咳)` `(？)` など）は**書かないでください**。

### 気にしなくてよいこと（自動で処理されます）
- 大文字／小文字、全角／半角（WiFi でも ｗｉｆｉ でもよい）
- 文末の「。」を付け忘れても問題ありません。
- 句読点は、文末「。」・疑問「?」・感嘆「!」だけで十分。読点「、」は自然な区切りにだけ。**付けすぎない**。

### やらないこと
- 話していない言葉を**足さない**。要約・言い換え・翻訳をしない。
- 区切り（セグメント）の位置は、**大きくズレているときだけ**直す。細かい時間合わせは不要です。

## 修正の例

| 自動の文字（修正前） | 直した後 | 直した理由 |
|---|---|---|
| そうですね | あー、そうですね | 冒頭の「あー」が抜けていた |
| 性格はこうなんですよ | 正解はこうなんですよ | 聞き間違い |
| （Bの波形が空欄） | はい | 相づち「はい」が入っていなかった |
| ふふ | (笑) | 笑い声はタグで |
| なんとかというサービスが | (不明)というサービスが | 固有名詞が聞き取れない |

## 提出のしかた

1. 画面でファイルを開き、音声を**最後まで再生**しながら各区切りを確認・修正する。
2. （必要なら区切りの位置を軽く調整する。）
3. 画面の **Export**（書き出し）で **`.annotations.json`** を保存する。**ファイル名は変えない**。
4. その JSON ファイルを提出する。

---

不明点があれば、推測で埋めずに `(不明)` を使ってください。正確さが最優先です。
